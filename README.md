## 🛠️ &nbsp;What I'm Building

**🛡️ [laravel-threat-detection](https://github.com/jay123anta/laravel-threat-detection)**
Passive threat-detection middleware for Laravel. Logs SQL injection, XSS, RCE, directory
traversal, SSRF, Log4Shell, scanner and bot activity across 175+ attack patterns, with
confidence scoring, a built-in dashboard, fail2ban export, Slack alerts and a REST API.
An IDS, not a WAF — it watches and reports, your app keeps serving.
